## Instructions pour commencer

1. Ouvrez ce dossier comme workspace dans votre éditeur.
2. Ajoutez vos fichiers et modifiez le code.
3. Pour envoyer les modifications sur GitHub :
   ```bash
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/<VOTRE_NOM_UTILISATEUR>/stage.git
   git branch -M main
   git push -u origin main
   ```
